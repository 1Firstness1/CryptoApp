# Тестовые сценарии для CryptoApp

## Unit-тесты

### 1. Options (7 тестов)
- autoOutputName в режиме encrypt добавляет .enc
- autoOutputName в режиме decrypt удаляет .enc
- autoOutputName в режиме decrypt добавляет .dec
- autoOutputName с пользовательским output
- autoOutputName с пустым input
- autoOutputName с длинным путем
- autoOutputName с существующим output

### 2. CryptoHeader (7 тестов)
- Конструктор по умолчанию
- Установка backend OpenSSL
- Установка backend Simple
- Генерация соли (ненулевая)
- Генерация IV (ненулевой)
- Запись/чтение заголовка
- Валидация корректного заголовка

### 3. KeyDerivationService (7 тестов)
- Валидный пароль
- Пустой пароль
- Длинный пароль (1000 символов)
- Одинаковый пароль + соль → одинаковый ключ
- Разная соль → разные ключи
- Разный пароль → разные ключи
- Пользовательское количество итераций

### 4. FileIOService (7 тестов)
- Существующий файл
- Несуществующий файл
- Пустой путь
- Открытие output (файл не существует)
- Открытие output (файл существует, force=false)
- Открытие output (файл существует, force=true)
- Открытие input (существующий)

## Интеграционные сценарии

### Сценарий 1: Шифрование и дешифрование файла
**Цель**: Проверить полный цикл encrypt → decrypt с верификацией содержимого
**Шаги**:
1. Создать тестовый файл с известным содержимым
2. Зашифровать файл с использованием OpenSSL backend
3. Расшифровать файл тем же паролем
4. Сравнить исходный и расшифрованный файлы
   **Ожидаемый результат**: Файлы идентичны

### Сценарий 2: Неправильный пароль при дешифровании
**Цель**: Проверить, что система корректно отклоняет неверный пароль
**Шаги**:
1. Зашифровать файл с паролем P1
2. Попытаться расшифровать с паролем P2 (P2 ≠ P1)
   **Ожидаемый результат**: Ошибка дешифрования

### Сценарий 3: Несовместимость backend
**Цель**: Проверить, что система обнаруживает несовместимость backend
**Шаги**:
1. Зашифровать файл с backend OpenSSL
2. Попытаться расшифровать с backend Simple
   **Ожидаемый результат**: Ошибка несовместимости backend

### Сценарий 4: Файл не найден
**Цель**: Проверить обработку ошибки отсутствия входного файла
**Шаги**:
1. Указать несуществующий входной файл
2. Запустить операцию
   **Ожидаемый результат**: Ошибка с сообщением "input file does not exist"

### Сценарий 5: Защита от перезаписи
**Цель**: Проверить, что без флага --force файл не перезаписывается
**Шаги**:
1. Зашифровать файл, создать output.enc
2. Попытаться зашифровать другой файл в output.enc без --force
   **Ожидаемый результат**: Ошибка "output file already exists"

### Сценарий 6: Обработка большого файла
**Цель**: Проверить корректную работу с файлами >10MB
**Шаги**:
1. Создать файл размером 10MB
2. Зашифровать файл
3. Расшифровать файл
   **Ожидаемый результат**: Успешное шифрование/дешифрование, корректный размер

### Сценарий 7: Обработка пустого файла
**Цель**: Проверить корректную работу с файлами нулевого размера
**Шаги**:
1. Создать пустой файл (0 байт)
2. Зашифровать файл
3. Расшифровать файл
   **Ожидаемый результат**: Успешная операция, выходной файл также пустой

## Команды для запуска тестов

```bash
# Собрать проект с тестами
mkdir build && cd build
cmake -DBUILD_TESTS=ON ..
make

# Запустить unit-тесты
./tests/crypto_tests

# Запустить сценарии по отдельности
./tests/scenario_encrypt_decrypt
./tests/scenario_wrong_password
./tests/scenario_backend_mismatch
./tests/scenario_file_not_found
./tests/scenario_overwrite_protection
./tests/scenario_large_file
./tests/scenario_empty_file

# Запустить все тесты через CTest
ctest --output-on-failure
```
