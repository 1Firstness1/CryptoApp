# Crypto App

Консольная утилита для шифрования и дешифрования файлов по паролю.

## Возможности

- Режимы: `encrypt` / `decrypt`
- Backends: `openssl` / `simple`
- Алгоритм: AES-256-CBC
- Получение ключа из пароля: PBKDF2-HMAC-SHA256
- Потоковая обработка файлов (без загрузки всего файла в память)
- Безопасный ввод пароля (без отображения)
- Два режима запуска:
  - CLI по тегам
  - Интерактивное меню (если запустить без аргументов)

## Требования

- C++17 компилятор (`g++`/`clang++`)
- OpenSSL 3.x (заголовки и библиотеки)

## Запуск

### 1) Интерактивный режим (меню)
Если запустить программу без аргументов:
```bash
./crypto_app
```

В меню доступны:
- Encrypt file
- Decrypt file
- Help
- Exit

Во время пошагового ввода работают команды:
- `back` — шаг назад
- `menu` — вернуться в главное меню
- `exit` — выход из программы

### 2) CLI-режим

Если переданы аргументы, используется CLI:

```bash
./build/filecrypt --mode <encrypt|decrypt> --backend <openssl|simple|o|s> --in <input> [--out <output>] [--force]
```

Параметры:
- `--mode` — `encrypt` или `decrypt`
- `--backend` — `openssl`, `simple`, `o`, `s`
- `--in` — входной файл
- `--out` — выходной файл (опционально)
- `--force` — перезапись выходного файла
- `--help` — справка

## Примеры

Шифрование:
```bash
./build/filecrypt --mode encrypt --backend o --in "/Users/artem/test file.txt" --out "/Users/artem/test file.txt.enc"
```

Дешифрование:
```bash
./build/filecrypt --mode decrypt --backend openssl --in "/Users/artem/test file.txt.enc" --out "/Users/artem/test file_restored.txt"
```

Авто-имя выходного файла:
```bash
./build/filecrypt --mode encrypt --backend s --in "./notes.txt"
```
В этом случае выходной файл будет `notes.txt.enc`.

## Коды завершения

- `0` — успех
- `1` — ошибка выполнения операции шифрования/дешифрования
- `2` — ошибка аргументов/ввода

---

## Возможные ошибки и решения

### `fatal error: 'openssl/evp.h' file not found`
OpenSSL dev-пакет не установлен или компилятор не видит include-путь.  Для решения нужно установить пакет или собрать с явным include-путём

### Неверный пароль или повреждённый файл при decrypt
Проверьте:
- правильность пароля
- соответствие backend (`openssl`/`simple`)
- целостность файла

### Файл не найден
Проверьте путь и лишние пробелы в начале/конце строки.

## Безопасность

- Не храните пароль рядом с зашифрованным файлом
- Используйте длинные уникальные пароли
- Перед передачей важных данных делайте тестовое шифрование/дешифрование на копии файла

## Структура проекта

- `/src/main.cpp` — точка входа, CLI + интерактивное меню
- `/include/crypto_app.h` — интерфейс и структура аргументов
- `/src/crypto_app.cpp` — реализация шифрования/дешифрования и вспомогательные функции
- `CMakeLists.txt` — настройки запуска и сборки проекта
